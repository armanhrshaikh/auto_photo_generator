# Auto 4x6 Passport Photo Generator

Easily create a **print-ready 4x6-inch photo layout** with **eight (8) identical passport-size photos (45mm x 35mm)** using this simple script-based tool. Perfect for passport, visa, ID, or other official photo requirements.

## Features

- Automatically arranges 8 passport-sized photos on a 4x6 canvas
- Compatible with **Windows** and **Linux**
- Requires only **ImageMagick** (free and open-source)
- High-resolution output at **300 DPI**
- Simple to use—no design skills required

---

## Requirements

- [ImageMagick](https://imagemagick.org/script/download.php) (must be installed and accessible in system path)

---

## Passport Photo Specs

- Standard size: **45mm height × 35mm width**
- Pixel equivalent at 300 DPI: **375px height × 300px width**
